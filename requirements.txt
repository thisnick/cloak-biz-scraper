# The MCP server, and the web stack under it. Pinned as a set, because each
# one's range is what forces the next:
#
#   * mcp 2.x depends on sse-starlette>=3; every sse-starlette from 3.1 on
#     requires starlette>=0.49.1.
#   * fastapi 0.115.6 capped starlette below 0.42, so it had to move too;
#     0.128.8 accepts anything below starlette 1.0.
#   * starlette is pinned at 0.50.0 — new enough for sse-starlette, still 0.x.
#     Left to fastapi's range it would float to the newest 0.x at install time,
#     and newer fastapi lines float to starlette 1.x, a major version this app
#     has not been tested against. Moving to it is its own change.
#
# `pip check` passes on this set. Behaviour that moved with it: fastapi now
# hands an EMPTY form value to a Form(None) parameter as its default — see
# routes/ui.py profile_edit, which reads the raw form for that reason.
